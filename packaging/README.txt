AULA Control 1.0

ESPAÑOL

Aplicación para la unidad EPOMAKER EA75 / AULA F75 comprobada en este proyecto.
Control de iluminación por USB y receptor 2.4 GHz. El control RGB y la batería
por Bluetooth no están implementados. La batería no está disponible por USB.

Requisitos: Windows 10 2004 o posterior, x64, y un controlador de gráficos con
soporte Vulkan. Se incluyen las bibliotecas de ejecución de C++ necesarias.

La X puede ocultar la ventana. Para terminar, elige Salir de AULA Control en
Preferencias o en el menú del icono de la bandeja junto al reloj.

Los perfiles y preferencias se guardan en %LOCALAPPDATA%\AulaControl.
Actualizar o desinstalar conserva esa carpeta. Iniciar con Windows es opcional
y se controla desde Preferencias. Si ya estaba activado, el instalador cambia
su ruta a la aplicación instalada. Desinstalar elimina solo esa ruta de inicio.

La vista previa sigue el último envío de AULA; la fase de la animación es
aproximada. No lee cambios hechos con la perilla. El remapeo multimedia es una
opción global de Windows que sustituye Silencio mientras AULA está abierta.

ENGLISH

Application for the EPOMAKER EA75 / AULA F75 unit verified in this project.
Lighting control over USB and the 2.4 GHz receiver. Bluetooth RGB/battery
control is not implemented. Battery information is unavailable over USB.

Requirements: Windows 10 version 2004 or later, x64, and a Vulkan-capable
graphics driver. Required C++ runtime libraries are included.

Closing the window may hide it. To quit, choose Exit AULA Control in Settings
or from its tray menu beside the Windows clock.

Profiles and preferences are stored in %LOCALAPPDATA%\AulaControl.
Updating or uninstalling preserves this folder. Start with Windows is optional
and is controlled in Settings. Setup updates an existing startup registration
to the installed application. Uninstall removes only its own startup path.

The preview follows AULA's last send; animation phase is approximate. It does
not read changes made using the knob. The optional multimedia remap globally
replaces Windows Mute while AULA is running.
